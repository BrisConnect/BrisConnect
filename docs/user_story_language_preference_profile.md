# User Story: User — Set Language Preference in Profile

## User Story

**As a** User,  
**I want to** select my preferred language in my profile,  
**So that** the app displays content in a language I understand.

## Acceptance Criteria

- User can open the language settings from their profile.
- User can select a preferred language from a supported list.
- Selected language is saved to the user profile.
- App interface updates to the selected language immediately after saving.
- User can change the language at any time.
- Unsupported languages are not shown in the list.

## Non-Functional Requirement

- **Usability:** The language selection process must require **no more than three taps** from opening profile settings.
