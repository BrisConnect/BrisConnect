# User Story: Visitor — Search Local Food Businesses

## User Story

**As a** Visitor,  
**I want to** search for local food businesses,  
**So that** I can discover dining options near me.

## Acceptance Criteria

- Visitor can enter a search keyword (e.g. cuisine type, business name, dish).
- Visitor can filter results by distance, rating, price range, and opening hours.
- Search results display business name, cuisine type, rating, distance, and thumbnail image.
- Tapping a result opens the business digital card with full details.
- Empty search state shows a friendly message with suggestions.

## Non-Functional Requirement

- **Performance:** Search results must load within **2 seconds** under normal network conditions.
